# Agentic PDLC — Thought Atlas

An interactive, self-contained exploration of the emerging Agentic Product Development Lifecycle (APDLC) mental model, based on five discussion artifacts synthesized on October 28, 2026.

## Status and intent — read this first

This is a **point-in-time capture of an evolving mental model**, taken on October 28, 2026. It is:

- **Not ready for publication.** It is a working draft shared in the open, not a finished piece.
- **Not complete.** Whole areas of the model are missing, thin, or marked as open questions.
- **Not verified.** Nothing here has been validated against production systems, external research, or organizational adoption.

Its only purpose is to **provoke further contemplation and conversation**. Treat every position, question, diagram, and lifecycle stage as provisional. The atlas explicitly distinguishes user positions and conversational alignments, assistant-proposed designs, and synthesized hypotheses. It is not an approved architecture, a governance policy, or evidence of a production implementation or external enterprise validation.

## Explore

Open `index.html` directly in a modern browser. No installation, build process, account, web server, or dependencies are required.

The atlas provides:

- An overview of eight conceptual pillars
- An interactive relationship graph
- Fourteen positions and proposals with rationale and evidence boundaries
- Eighteen prioritized open questions, with filtering
- An illustrative idea-to-operations lifecycle walkthrough
- Six tensions and concrete stress-test scenarios
- A source register for provenance

## Publish with GitHub Pages

1. Create a GitHub repository, such as `agentic-pdlc-atlas`.
2. Extract the ZIP and add its contents at the **repository root**, with `index.html` next to this README.
3. Commit and push to your default branch (normally `main`).
4. In GitHub, navigate to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
6. After the Pages deployment completes, GitHub will show your site URL.

For local development, simply edit `index.html` and refresh the browser.

The app uses a deliberately curated dataset embedded in `index.html`. A future version could extract concepts, decisions, source references, and questions into structured data files for easier review through pull requests.

## Source material

The five underlying knowledge files are **not included** in this distribution. The interface contains short source pointers (`S1`–`S5`), described in the source register. Before publishing full transcripts or project artifacts, review them separately for disclosure suitability.
